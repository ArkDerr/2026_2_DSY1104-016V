```text
| Etiqueta    | Nombre / corresponde a           | ¿Para qué sirve?                                               |
| ----------- | -------------------------------- | -------------------------------------------------------------- |
| `<html>`    | Documento HTML                   | Contiene toda la página HTML                                   |
| `<head>`    | Cabecera del documento           | Contiene configuración, CSS, título, metadatos, etc.           |
| `<meta>`    | Metadatos                        | Configura información como codificación UTF-8 y responsive     |
| `<title>`   | Título                           | Define el título mostrado en la pestaña del navegador          |
| `<link>`    | Enlace a recurso                 | Permite cargar Bootstrap, CSS, iconos, etc.                    |
| `<body>`    | Cuerpo                           | Contiene todo lo que se visualiza en la página                 |
| `<header>`  | Encabezado                       | Agrupa contenido introductorio o superior                      |
| `<nav>`     | Navegación                       | Contiene el menú principal de navegación                       |
| `<main>`    | Contenido principal              | Agrupa el contenido principal de la página                     |
| `<section>` | Sección                          | Divide el contenido en áreas temáticas                         |
| `<article>` | Artículo/contenido independiente | Representa contenido independiente, como un producto           |
| `<div>`     | División/contenedor              | Agrupa elementos principalmente para estructura y diseño       |
| `<footer>`  | Pie de página                    | Contiene información final, enlaces, contacto, copyright, etc. |
| `<h1>`      | Encabezado nivel 1               | Título principal                                               |
| `<h2>`      | Encabezado nivel 2               | Título de una sección                                          |
| `<h3>`      | Encabezado nivel 3               | Subtítulo, por ejemplo nombre de producto                      |
| `<p>`       | Párrafo                          | Texto o descripción                                            |
| `<span>`    | Contenedor en línea              | Permite marcar una pequeña parte de un texto                   |
| `<a>`       | Anchor / enlace                  | Crea enlaces a páginas o secciones                             |
| `<img>`     | Imagen                           | Muestra una imagen                                             |
| `<i>`       | Texto alternativo/itálico        | En nuestro proyecto se usa principalmente con Bootstrap Icons  |
| `<form>`    | Formulario                       | Agrupa campos para ingreso de datos                            |
| `<label>`   | Etiqueta de formulario           | Describe qué debe ingresar el usuario                          |
| `<input>`   | Campo de entrada                 | Permite ingresar email, contraseña, texto, etc.                |
| `<button>`  | Botón                            | Crea un botón                                                  |
| `<script>`  | Script                           | Permite cargar o escribir JavaScript                           |
```
